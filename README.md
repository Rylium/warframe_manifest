# warframe_manifest
Warframe JSON Manifest Explorer

> [!NOTE]
> The version of the data is based on the `43.0` version of WARFRAME.


> [!TIP]
> The current data blueprint is based on InternalName, like this:
```text
Characters
│
└── Tenno
    │
    └── Accessory
        │
        └── Scarves
            │
            ├── GrnBannerScarf
            │   └── [image] [image] [image] ...
            │
            ├── PrimeScarfD
            │   └── Cloth
            │       └── [image] [image] ...
            │
            └── ...
```
